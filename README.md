# Employee Laptop Request Application

A ServiceNow-based application designed to manage employee laptop requests through a structured and automated process. The project covers request submission, approval workflow, validation, security, notifications, and deployment.

## Project Documentation – 6 Phases

### Phase 1 – Requirement Analysis & Planning
Defines the business objective, project scope, functional requirements, request fields, stakeholders, roles, and overall process flow.

### Phase 2 – Backend Development & Configuration
Covers the creation of the ServiceNow application, custom table, fields, Record Producer, approval relationship, and employee-facing Service Catalog.

### Phase 3 – Workflow Development & Execution
Implements the request lifecycle using Flow Designer, including request status initialization, manager approval, approval/rejection handling, and notifications.

### Phase 4 – Business Rules, Security & Validation
Covers Business Rules, role and group configuration, ACLs, access control, and functional validation scenarios to ensure the application behaves correctly.

### Phase 5 – Deployment & Final Presentation
Covers Update Set verification, preview and deployment, configuration validation, final project demonstration, and project handover.

### Phase 6 – Conclusion
Summarizes the project achievements, ServiceNow skills demonstrated, complete request process, and possible future enhancements.
